# Wireframe Design System & Text Layout (ASCII)

ออกแบบ Text Wireframe (ASCII Layout) สำหรับระบบบริหารจัดการคลังสินค้า (Inventory Management System) โดยเน้นการตอบโจทย์ **คุณสมเกียรติ (ผู้จัดการคลังสินค้าและการจัดซื้อ)** ที่ต้องการความรวดเร็ว แม่นยำ อ่านข้อมูลได้ชัดเจน ไม่ซับซ้อน พร้อมปฏิบัติตามหลัก Usability และ Accessibility (WCAG compliant)

---

## 1.หน้า Login (เข้าสู่ระบบ)

ออกแบบแนวมินิมอลเน้น Focus ตัวฟิลด์ ป้องกันการป้อนข้อมูลผิดพลาด

### Default State (หน้าปกติ)

```text
+-----------------------------------------------------------------------+
|                                                                       |
|                       [ Logo / Company Name ]                         |
|                   ระบบบริหารจัดการคลังสินค้า (Inventory System)          |
|                                                                       |
|  +-----------------------------------------------------------------+  |
|  | เข้าสู่ระบบ                                                     |  |
|  |                                                                 |  |
|  |  * อีเมล / ชื่อผู้ใช้งาน (Email / Username)                          |  |
|  |  [ somkiat@company.com                                         ]  |  |
|  |  *(ตัวอย่าง: user@company.com)                                   |  |
|  |                                                                 |  |
|  |  * รหัสผ่าน (Password)                                          |  |
|  |  [ ************                                                ]  |  |
|  |                                                                 |  |
|  |  [X] จดจำการเข้าสู่ระบบ (Remember Me)   [ ลืมรหัสผ่าน? ]          |  |
|  |                                                                 |  |
|  |  +-----------------------------------------------------------+  |  |
|  |  |                 [ เข้าสู่ระบบ (Login) ]                     |  |  | (Primary Button)
|  |  +-----------------------------------------------------------+  |  |
|  |                                                                 |  |
|  +-----------------------------------------------------------------+  |
|                                                                       |
+-----------------------------------------------------------------------+

```

## Validation Error State (กรณีระบุข้อมูลไม่ถูกต้อง)

```text
|  * จำนวนนำเข้าเริ่มต้น (Initial Stock)         * จุดเตือนสั่งซื้อเติม (Reorder Point)              |
|  [ -5                                   ]  [ ABC                                  ]  |
|  ⚠ กรุณากรอกตัวเลขจำนวนเต็มบวก (เช่น 0, 10)  ⚠ กรุณากรอกเฉพาะตัวเลขเท่านั้น (เช่น 5, 10)         |

```
## 2.หน้า Dashboard (แผงควบคุมหลัก)

เน้นการเห็นภาพรวมสินค้าคงคลัง สินค้าใกล้หมด (Low Stock) เพื่อช่วยให้คุณสมเกียรติตัดสินใจสั่งซื้อได้ทันที

```text
+--------------------------------------------------------------------------------------------------------+
| [Logo] Inventory System  |  [Dashboard]  [สินค้า]  [รายงาน]               [🔔 3] [คุณสมเกียรติ (Manager) 🗂] |
+--------------------------------------------------------------------------------------------------------+
|                                                                                                        |
|  ภาพรวมคลังสินค้า (Dashboard Overview)                                    +-------------------------+  |
|                                                                           |  [+ เพิ่มสินค้าใหม่]    |  | (Primary Button)
|  +-----------------------+  +-----------------------+  +---------------++ +-------------------------+  |
|  | สินค้าทั้งหมด         |  | สินค้าใกล้หมดคลัง     |  | รออนุมัติจัดซื้อ  |                            |
|  | 1,240 รายการ          |  | 12 รายการ             |  | 5 รายการ        |                            |
|  +-----------------------+  +-----------------------+  +-----------------+                            |
|                                                                                                        |
|  ----------------------------------------------------------------------------------------------------  |
|  รายการสินค้าที่ต้องรีบสั่งซื้อ (Low Stock Alert)                                                      |
|                                                                                                        |
|  [ค้นหาสินค้า / SKU...]   [ หมวดหมู่: ทั้งหมด v ]   [ สถานะ: ทั้งหมด v ]         [🔍 ค้นหา]   [🔄 รีเฟรช] |
|                                                                                                        |
|  +----------+----------------------------------+---------------+-------------+----------+-----------+  |
|  | รหัส SKU  | ชื่อรายการสินค้า                 | หมวดหมู่      | จำนวนคงเหลือ| จุดสั่งซื้อ| การจัดการ  |  |
|  +----------+----------------------------------+---------------+-------------+----------+-----------+  |
|  | CBL-001  | สายไฟ VCT 2x2.5 Sq.mm. (100m)    | อุปกรณ์ไฟฟ้า  | 5 ม้วน      | 15 ม้วน  | [สั่งซื้อ] |  |
|  | PIP-042  | ท่อ PVC ท่อน้ำไทย 1/2 นิ้ว (ชั้น 13.5)| วัสดุก่อสร้าง  | 12 ท่อน     | 50 ท่อน  | [สั่งซื้อ] |  |
|  | BRK-010  | เบรกเกอร์ 2P 32A                 | อุปกรณ์ไฟฟ้า  | 2 ตัว       | 10 ตัว   | [สั่งซื้อ] |  |
|  +----------+----------------------------------+---------------+-------------+----------+-----------+  |
|  แสดง 1-3 จาก 12 รายการ                                                    [< ก่อนหน้า]  1  [ถัดไป >]   |
|                                                                                                        |
+--------------------------------------------------------------------------------------------------------+

```
## 3.หน้า Add Product (เพิ่มสินค้าใหม่)

แยกประเภทข้อมูลชัดเจน ใช้ Layout แบบ 2 คอลัมน์บนจอแล็ปท็อปเพื่อลดระยะการสกอร์หน้าจอ

### Default State (หน้าปกติ)

```text
+--------------------------------------------------------------------------------------------------------+
| [Logo] Inventory System  |  [Dashboard]  [สินค้า]  [รายงาน]               [🔔 3] [คุณสมเกียรติ (Manager) 🗂] |
+--------------------------------------------------------------------------------------------------------+
|                                                                                                        |
|  < กลับไปหน้าจัดการสินค้า / เพิ่มสินค้าใหม่ (Add New Product)                                            |
|                                                                                                        |
|  +--------------------------------------------------------------------------------------------------+  |
|  |  ข้อมูลทั่วไป (General Information)                                                              |  |
|  |                                                                                                  |  |
|  |  * ชื่อสินค้า (Product Name)                   * รหัสสินค้า (SKU)                                |  |
|  |  [ สายไฟ THW 1x1.5 Sq.mm.                  ]  [ ELE-THW-001                     ]  |  |
|  |                                                                                                  |  |
|  |  * หมวดหมู่ (Category)                           แบรนด์ / ผู้ผลิต (Brand)                         |  |
|  |  [ อุปกรณ์ไฟฟ้า                         v ]  [ Yazaki                          ]  |  |
|  |                                                                                                  |  |
|  |  รายละเอียดสินค้า (Description)                                                                   |  |
|  |  [ สายไฟทองแดงหุ้มฉนวน PVC ความยาวม้วนละ 100 เมตร                                              ]  |  |
|  |  [                                                                                               ]  |  |
|  +--------------------------------------------------------------------------------------------------+  |
|                                                                                                        |
|  +--------------------------------------------------------------------------------------------------+  |
|  |  การจัดเก็บและราคา (Inventory & Pricing)                                                          |  |
|  |                                                                                                  |  |
|  |  * หน่วยนับ (Unit)                             * ราคาต้นทุน/หน่วย (Cost Price)                   |  |
|  |  [ ม้วน                                 v ]  [ 850.00                          ]  |  |
|  |                                                                                                  |  |
|  |  * จำนวนนำเข้าเริ่มต้น (Initial Stock)         * จุดเตือนสั่งซื้อเติม (Reorder Point)              |  |
|  |  [ 50                                    ]  | 10                                   ]  |  |
|  |  *(จำนวนชิ้น/ม้วนในคลังปัจจุบัน)                 *(ระบบจะเตือนเมื่อสินค้าเหลือเท่านี้หรือน้อยกว่า)  |  |
|  |                                                                                                  |  |

|  |  [ Zone A - Rack 03 - Shelf 2            ]                                                       |  |
|  +--------------------------------------------------------------------------------------------------+  |
|                                                                                                        |
|  ----------------------------------------------------------------------------------------------------  |
|                                                     [ ยกเลิก ]   [ บันทึกข้อมูลสินค้า ]                |  |
|                                                   (Secondary)        (Primary)                         |

```
